# 用户行为数据离线ETL项目

基于 Linux + Shell + Hive 构建用户行为日志离线分析流程，
模拟电商用户行为数据处理过程，实现从原始日志、
DWD明细层、DWS汇总层到ADS报表层的数据仓库链路。


## 技术栈

Linux
Shell
Hive
SQL
Docker
Hadoop生态


## 项目功能

1. 用户行为日志采集与清洗

- 读取用户行为日志文件
- 按日期进行分区管理
- 完成数据格式规范化


2. DWD明细层

建立用户行为明细表：

dwd_user_behavior_detail

字段：

- 用户ID
- 行为时间
- 行为类型
- 分区日期


3. DWS汇总层

统计用户粒度行为：

- 登录次数
- 浏览次数
- 购买次数


4. ADS报表层

生成用户行为分析指标：

- DAU
- 登录用户数
- 购买次数
- 购买用户数


5. 自动化任务

通过Shell脚本实现：

- ETL任务执行
- 日志记录
- 结果文件生成
